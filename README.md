**Modern Termux:MOTD** is the official companion and dynamic MOTD (Message of the Day) designer plugin for [Modern Termux](https://github.com/Furkan00487/modern-termux).

## Features
- **Zero background battery usage:** Runs only when opened to configure or apply your MOTD.
- **Dynamic live stats:** Generates ultra-lightweight shell hooks for Battery, RAM, Storage, and Uptime.
- **`sharedUserId="com.termux"`:** Seamlessly writes directly into Modern Termux directories without root.
- **Modern Jetpack Compose UI:** Material 3, Edge-to-Edge, and live terminal preview.
